# CheeseTail · 치즈테일

치즈테일 Android 앱 개발 저장소입니다.

## 현재 구현

- 앱 실행 시 치즈테일 메인 화면 표시
- 메인 화면의 `게임 시작` 영역 터치 → 멀티플레이 로비 진입
- 멀티플레이 로비는 등록된 4개 이미지 중 매 진입 시 무작위로 1개 표시
- 직전에 표시된 로비 이미지는 연속해서 다시 나오지 않음
- `방만들기` → 방 이름 / 2·3·4인 / 일반전·친선전 / 비공개 방 설정
- 방 생성 후 게임 대기실 진입
- 대기실에서 테스트 봇 채우기 / 준비 상태 / 게임 시작 처리
- `자동매칭` → 매칭 안내 → 4인 대기실 자동 진입
- 대기실의 `게임 시작` → 실제 플레이 가능한 로컬 원카드 테스트 게임 진입
- 음식 4종: 치즈 / 빵 / 소세지 / 쿠키
- 일반 카드 A, 2~10, J, Q, K
- 같은 음식 또는 같은 숫자/문양 카드만 낼 수 있음
- 낼 카드가 없으면 더미에서 1장 뽑고 턴을 넘김
- 테스트 봇이 자동으로 합법적인 카드를 내거나 1장 뽑음
- 손패를 먼저 모두 내려놓은 플레이어가 승리
- Android 뒤로가기: 게임 → 로비 → 홈 순으로 이동
- GitHub Actions에서 Debug APK 자동 빌드 및 artifact 생성

## 현재 버전

- Android 앱 버전: `0.3.1`
- `versionCode 4`
- 최종 고해상도 PNG 5장 포함 GitHub Actions Build #27 실빌드 성공

## Android 기준

- `compileSdk 35`
- `targetSdk 35`
- `minSdk 26`
- Java 11 소스 호환
- GitHub Actions JDK 17 / Gradle 8.7

## APK 자동 빌드

`main` 브랜치에 코드가 push되거나 Actions에서 수동 실행하면
`.github/workflows/android.yml`이 `app-debug.apk`를 생성합니다.
Pull Request에서도 동일한 빌드 검증을 수행합니다.

빌드 결과는 GitHub의 **Actions → Build CheeseTail APK → Artifacts → cheesetail-debug-apk**에서 받을 수 있습니다.

## 화면 리소스

- `home_main.png` : 최종 고해상도 치즈테일 메인 화면
- `lobby_01.png` ~ `lobby_04.png` : 최종 고해상도 랜덤 멀티플레이 로비

기존 경량 JPG 테스트 리소스는 제거했고, 사용자가 직접 업로드한 원본 PNG 5장을 Android 리소스로 사용합니다.

## 다음 개발 순서

1. 점프 / 뒤로가기 / 음식 바꾸기 특수 카드 엔진 구현
2. 숨숨 / 번쩍 +3 / 잡았다 +5 Joker 카드 구현
3. 게임 대기실 및 방 목록의 실제 네트워크 동기화
4. 캐릭터 패시브 / 등급 / 수집 시스템 연결
5. 상점 / 카드 도감 / 이벤트 / 랭킹 / 친구 / 퀘스트 연결

향후 치즈테일의 Android 코드와 게임 리소스는 이 저장소를 기준으로 관리합니다.
